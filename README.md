# SF6 NAVI | ストリートファイター6 実戦攻略＆トレモ設定ナビ

ストリートファイター6（Year 2環境）における全26キャラクター（初期18体 ＋ Year 1 DLC 4体 ＋ Year 2 DLC 4体完備）の特徴、必修コンボ、立ち回り・膠着打開策、キャラ別対策、およびプロ動画ベースのトレーニングモード設定を網羅した実践Webアプリケーションです。

---

## 主な機能と特徴

1. **直感的な矢印コマンド表記**
   - テンキー表記（236Pなど）ではなく、ゲーム内表記に準拠した矢印記号（`↓↘→+P`、`→↓↘+P`、`［↓］↑+K`、`立強P`、`↓弱P`、`→+SP` など）で表示。
   - クラシック / モダンのワンクリック切り替え対応。

2. **全26キャラクター完全網羅（最優先：リュウ / テリー / 不知火舞 / エレナ）**
   - **リュウ (Ryu)**: 波掌撃固め・電刃練気・高火力基礎＆SA3コンボ
   - **テリー (Terry)**: パワーチャージ・クラックシュート・モダンワンボタン対空ライジングタックル
   - **不知火舞 (Mai Shiranui)**: 焔ストックシステム・花蝶扇ホールド・飛翔龍炎陣
   - **エレナ (Elena)**: カポエイラ足技リーチ・ライノホーン・SA2ヒーリング回復
   - **全26キャラ**: ルーク、豪鬼、ケン、ベガ、エド、ガイル、春麗、キャミィ、ジュリ、ディージェイ、JP、ザンギエフ、マリーザ、ラシード、A.K.I.、ジェイミー、キンバリー、マノン、ブランカ、E.本田、ダルシム、リリー

3. **プロ直伝！トレモ完全活用講座（YouTube 3大動画ベース）**
   - **あくあ氏 直伝**: ショートカット操作（Fnボタン即リスタート、左右入れ替え）とフレームメーターの見方・活用法
   - **どぐら氏 直伝**: リバーサル設定（最速暴れ・無敵技・ジャンプ・バクステ・遅らせグラップ）＆ガード設定「ランダム」の重要性と練習法
   - **五郎氏 直伝**: 実戦で負けた「苦手技」をトレモで即座に特定し、確反・差し返し・割り込みの解答を見つける反省ルーティン

4. **キャラクター別 対戦対策（Matchup）**
   - キャラクター別の相性目安・戦術ポイント
   - 相手の警戒すべき主力技リスト
   - ガード時・空振り時の確定反撃（確反）表
   - 立ち回り・距離別の対策アドバイス

5. **必修コンボ集（クラシック / モダン両対応）**
   - 基礎小技、中攻撃確認、生ラッシュ、パニッシュカウンター、画面端インパクト、SA3リーサル
   - レシピのワンクリッククリップボードコピー
   - ドライブ・SAゲージ消費量、ダメージ目安、解説付き

6. **立ち回り＆膠着打開ガイド**
   - 遠・中・近距離の意識配分
   - 相手が固まった際のお見合い・膠着をこじ開ける具体策
   - バーンアウト（BO）時の攻防（相手BOへの詰め方、自身BO時の凌ぎ方）

7. **トレモ支援ツール**
   - 全キャラ共通のデイリー基礎ルーティン（対空3択、インパクト返し、ヒット確認等）
   - 日々の練習進捗をブラウザに自動保存するチェックリスト＆達成率ゲージ
   - 集中タイマー（3分・5分・10分・15分）
   - マイ個人対策メモ（キャラ別に自動保存）

## ローカルでの起動方法

```bash

npm install

# 開発サーバー起動（http://localhost:5173）
npm run dev

# プロダクションビルド（dist/ 出力）
npm run build
```

## GitHub へのデプロイ手順

本プロジェクトは GitHub Pages への自動デプロイワークフロー（`.github/workflows/deploy.yml`）を完備しています。以下の手順で GitHub にプッシュするだけで、Webサイトが自動公開されます。

### 1. GitHub 上で新規リポジトリを作成
1. GitHub (https://github.com) にログインし、右上の「+」→「New repository」をクリック。
2. Repository name（例: `sf6-guide-tool`）を入力。
3. **「Initialize this repository with:」のチェック（README, .gitignore 等）はすべて外した状態（空のリポジトリ）**で「Create repository」をクリック。

### 2. ローカルから GitHub へプッシュ

ターミナル（PowerShell / Git Bash 等）でプロジェクトディレクトリに移動し、以下のコマンドを実行します：

```bash
# リモートリポジトリの登録（<username> をご自身のアカウント名に置き換えてください）
git remote add origin https://github.com/<username>/sf6-guide-tool.git

# main ブランチへプッシュ
git push -u origin main
```

### 3. GitHub Pages の設定（初回のみ）
1. GitHub のリポジトリページで **Settings** タブを開きます。
2. 左メニューの **Pages** を選択します。
3. **Build and deployment** の **Source** を **「GitHub Actions」** に設定します。
4. 数分後、GitHub Actions のビルドが完了すると、ページ上部に公開URL（`https://<username>.github.io/sf6-guide-tool/` 等）が表示され、アクセス可能になります。
